# Facebook 教材介紹文

🌲 真正的野外求生，不是表演鑽木取火，而是從「不讓危機發生」開始。

這次完成了《野外求生安全手冊》，提供給國小高年級、國中生、親子家庭與戶外初學者閱讀。內容以臺灣山林情境為核心，參考國內外政府、國家公園、公共衛生與急救機構資料，整理成清楚、可查找的安全指南。

網站包含：

✅ 有毒植物：不採、不食不明動植物  
✅ 火與庇護：火的三要素、營火結構與臺灣山林用火規範  
✅ 水質淨化：選源、澄清、煮沸、過濾與保存  
✅ 方位判讀：地圖、指北針、離線地圖與迷途 STOP  
✅ 禦寒：分層穿著、隔風雨與失溫警訊  
✅ 野生動物：黑熊、山豬、獼猴、虎頭蜂與毒蛇應變  
✅ 行前準備：十項必需品、留守計畫、求救通報與無痕山林  
✅ 自主學習：臺灣與國際權威戶外安全網站

全站採純閱讀設計，沒有測驗、動畫或進度追蹤；7 張情境圖片皆由 Image 2.0 生成，讓學生專注在內容與安全決策上。
