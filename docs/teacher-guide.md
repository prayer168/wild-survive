# 教師與帶領者使用說明

## 建議對象與時間

- 對象：國小五年級至國中低年級、親子團體、戶外活動初學者
- 建議時間：45–60 分鐘
- 領域：自然科學、健康與體育、綜合活動、戶外教育、安全教育

## 學習目標

學生能：

1. 說出行前計畫與十項必需品的重要性。
2. 運用 STOP 原則描述迷途後的安全決策。
3. 說明不明植物不採不食、天然水需處理、山林不可任意生火。
4. 比較地圖、指北針、離線地圖與自然線索的可靠性。
5. 辨認失溫、嚴重過敏與毒蛇咬傷需立即求援的警訊。
6. 依黑熊、虎頭蜂、獼猴等情境選擇降低衝突的做法。
7. 說明燃燒三要素，並比較 15 種生火方法的條件、限制與主要危險。
8. 面對強風、潮濕、禁火或缺乏成人監督時，能主動選擇「不生火」。
9. 依序完成澆水、攪拌、再澆水、檢查與完全冷卻。
10. 說明自製浮水指南針的地磁原理、校驗方式與不能取代正式工具的限制。
11. 能辨認磁力干擾、磁北與真北差異，並以紙圖、正式指北針、GPS 和地標交叉確認。
12. 面對自然線索不足或迷途情境時，先停止移動、維持安全、清楚通報並等待指示。

## 建議教學流程

1. **情境引入（5 分鐘）**：觀看首頁圖，找出隊伍已準備的安全裝備。
2. **行前與 STOP（10 分鐘）**：以「天黑前發現走錯岔路」討論停下與繼續走的差異。
3. **六大章節（25 分鐘）**：每組負責一章，整理「可以做／不要做／何時求援」。
4. **全班統整（10 分鐘）**：依立即危險、醫療、保暖、定位、水食重新排列優先順序。
5. **延伸任務（課後）**：選一條合法步道，查天氣、路況、申請需求、撤退點與留守資訊。

### 生火互動擴充建議（額外 20～30 分鐘）

1. 先用火三角模擬移除燃料、熱或氧氣，要求學生先預測再操作。
2. 將全班分組比較火柴、火鋼、放大鏡與摩擦取火，重點放在「條件與限制」，不進行真火比賽。
3. 進行情境判斷、營地找錯與完全滅火排序。
4. 最後完成安全生火題組；答錯時依題目提供的連結返回相關教材。
5. 課後自主學習只指定可信資源，影音或操作性較高的文章建議由成人陪同閱讀。

### 指南針與辨位術擴充建議（額外 20～30 分鐘）

1. 先操作自製指南針數位步驟，討論「南北軸」與「哪端是北」為何不是同一件事。
2. 使用干擾模擬比較淨空桌面、手機、鋼瓶與磁鐵，建立重測與交叉確認習慣。
3. 旋轉數位地圖完成定向，再要求學生指出至少兩項可與現場核對的地形證據。
4. 比較日影、星空、青苔、GPS 與紙圖／指北針，將方法依可靠度與限制分類。
5. 完成迷途決策排序與 30 題整合闖關；不安排學生在真實山林中自行導航。

## 安全界線

- 不在校園或山林進行野外植物試吃。
- 點火實作僅能在合法場地、具滅火設備且有合格成人直接監督時進行。
- 未成年人不得把本網站的數位模擬當成自行生火許可；強風、乾旱、禁火或枯草密集時一律取消用火。
- 不示範汽油、酒精噴灑、爆裂物或其他揮發性助燃物。
- 不以生成圖片作為物種鑑定依據。
- 不以網站內容代替正式急救、導航、戶外領隊或野外醫療課程。
- 自製指南針活動只在教室由成人管理尖針與磁鐵；不得把成品帶入野外作為主要或備援導航工具。
- 不把太陽、北極星、青苔、溪流或單一地標描述成保證方向正確的方法。
- 課綱代碼請教師依任教階段與最新版正式課綱手冊確認，本專案不杜撰代碼。

## 素養對應

- 自主行動：風險評估、裝備準備、資訊查核與自我照顧。
- 溝通互動：行程留守、清楚通報位置與團隊決策。
- 社會參與：遵守場域規範、尊重生命、無痕山林。
- 議題融入：戶外教育、安全教育、環境教育、防災教育、生命教育。
